# Internationalization

Release 0.6.0 introduces capability, not a complete translation.

- Stable internal mode: `assistant`.
- Locale source: `HAYVOZ_LANGUAGE`, private config, OS locale, then English.
- Initial localized terms: Spanish `Asistente`, English/French `Assistant`,
  Portuguese/Italian `Assistente`, and German `Assistent`.
- Lowercase localized terms are CLI aliases for the same command.

Persistence, environment keys, schema names, and log event names remain stable
and language-neutral. Future catalogs will translate messages without changing
automation or stored values.

To add a language, extend `ASSISTANT_TERMS`, add resolver/CLI tests, and document
the locale. Avoid adding an alias that collides with another command.
